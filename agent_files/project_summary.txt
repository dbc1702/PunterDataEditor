Use the screenshots as visual guidance for the record view. They show the kind of player-attribute layout used in management simulator games such as *Football Manager* and *Championship Manager*.

## Intended application

The main window will display the dataset’s `DogName` values in a list. Double-clicking a name will open a record view for that dog.

The record view should present the dog’s attributes in a style inspired by the supplied screenshots. Attribute values should be easy to scan, using either:

- A progress-bar style display, or
- A five-star rating display.

Choose the display that best fits the design, and keep it consistent across attributes unless there is a clear reason to vary it.

### Attribute scale

Dataset attributes are generally between 1 and 100. The game converts these values to a 1–20 scale by dividing by 5 and rounding down.

Examples:

- `TopSpeed = 100` → in-game value `20`
- `Agility = 76` → in-game value `15` (`76 / 5 = 15.2`, rounded down)

If an attribute is shown using five stars, calculate the rating by integer division by 20, equivalent to dividing by 5 and converting the resulting 1–20 value to a five-star display. Keep the original dataset value available wherever exact values matter. Do not silently replace or alter stored CSV values just to display a rating.
